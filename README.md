## Analyses in the manuscript

This repository accompanies the BE WELL manuscript submitted for publication. Manuscript notebooks are in `manuscript/scripts/`. Knit them from that directory. They read `../../data` and write the panels below to `manuscript/figures/`. Other outputs from those notebooks go to `exploratory/figures/`. Metagenomic read processing, profiling, and taxonomy-table scripts are in `processing/`. Package versions are listed in [`manuscript/r-packages.txt`](manuscript/r-packages.txt). The code is released under the [MIT license](LICENSE).

Figure 1 (trial schema, nectar preparation, and CONSORT diagram) is not generated by these notebooks. Panels 2C, 2D, and 4G are not generated by these notebooks either.

## Data availability

Tables used to draw the manuscript panels are in `data/`. The clinical table keeps subject number, gender, smoking status, age, race/ethnicity, IPAQ category, the four MET activity fields, consented and completed-all-visits flags, and the energy-residual EDIP, EDIH, and HEI-2015 scores used in Table 1. Diet scores, including deidentified `Username` and `userid` values, are in [`data/derived/bewelldietscore.07122022.csv`](data/derived/bewelldietscore.07122022.csv). The complete clinical export, the consent-date list, and both study-schedule workbooks stay in `T:/Labs/Spakowicz/bewell` and are not in this repository. The completed-all-visits flag used in Table 1 is stored in `data/derived/clinical_manuscript.rds`.

Sequencing reads, per-sample profiles, and the reference databases used to process them are on the Ohio Supercomputer Center. Paths are listed in [`data/external-files.md`](data/external-files.md). A public download link can be added there when the files are posted.
